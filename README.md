# SCT_ML_04
Developed a Hand Gesture Recognition system capable of identifying and classifying different hand gestures from image and video data. Implemented gesture detection, preprocessing, feature extraction, and real-time prediction using Python, OpenCV, MediaPipe, and TensorFlow for gesture-based human-computer interaction.
Used dataset for training of this model is given below :
https://www.kaggle.com/code/marusagar/hand-gesture-recognition-system/input?select=train
